# Agent C: UI (app/page.tsx, app/c/**, app/t/**)

Paste this whole file to your coding agent. Read `CONTRACT.md` first.

## Goal
Build the 5 pages against the CONTRACT API. Build them before the API exists by mocking with `fetch` wrappers in `lib/api.ts`. Only touch `app/**/page.tsx`, `app/layout.tsx`, `app/globals.css`, `components/**`, `lib/api.ts`.

## Look
Dark, one accent color (electric green `#22c55e` for verified, red `#ef4444` for rejected). Big numbers. Mobile-first. Tailwind only, no component library. Use the font `Inter` from `next/font/google`. Header text on every page reads "Headcount", with a small "Base Sepolia" pill.

## Pages

### `/` Create campaign (sponsor)
Form fields: event name, sponsor wallet, host wallet, USDC per head (default 5), cap (default 100). Submit to POST `/api/campaigns`. Show a one-time screen with **host PIN** and **sponsor PIN** in big type, a "Copy" button for each, and a warning: "Save these. They are shown once." Then show buttons for the Dashboard and Scanner links.

### `/c/[id]` RSVP (guest)
Show the campaign name and "Sponsored check-in. Free. No wallet needed." Fields: name, plus email or @telegram. Submit to POST `/rsvp`, then `router.push('/t/' + ticketId)`. Save the ticketId to `localStorage` key `hc_ticket_<campaignId>` (wrapped in try/catch). If one exists on load, show "You already have a ticket" with a link to it.

### `/t/[ticketId]` Ticket (guest phone)
- Poll GET `/api/tickets/[id]/qr` every 3 seconds.
- Big white-background QR (`qrcode.react`, size about 280, level "M") of `code`.
- A countdown bar draining over `expiresInMs`, and the label "Code refreshes every 30s. Screenshots won't work."
- Guest name plus campaign name.
- When `checkedIn` is true, replace everything with a full green screen: "✓ Checked in". Stop polling.

### `/c/[id]/scan` Scanner (host phone)
- PIN gate (6 digits). Keep it in component state only.
- `html5-qrcode` with `Html5Qrcode` (not the Scanner widget). Use `facingMode: "environment"`, fps 10, qrbox 250. Load it with a dynamic import (`ssr: false`) because it touches `window`.
- On decode: if the same text was scanned within 3 seconds, ignore it. POST `/checkin` `{ code, hostPin }`.
- Result overlay for 1.5 seconds:
  - 200: GREEN full screen, guest name, "Verified".
  - 409 `already_checked_in`: AMBER "Already checked in".
  - 400 `expired`: RED "Expired code. Ask the guest to show their live ticket."
  - Others: RED with the error.
  - 401: send them back to the PIN gate.
- Footer: running count "Verified this session: N".
- Note: the camera needs HTTPS. Show a clear message if `navigator.mediaDevices` is undefined.

### `/c/[id]/dashboard` Sponsor dashboard (public read; this is the demo screen)
- Poll `/stats` every 2 seconds.
- Top row with 3 big stat tiles: **Verified heads** `verified / cap`, **Paid to host** `paidUi hUSDC`, **In escrow** `escrowUi` (show a dash if null).
- A progress bar of verified/cap.
- **Big RSVP QR** (`window.location.origin + '/c/' + id`; don't read `APP_URL` client-side, it isn't exposed) on the right side with the caption "Scan to RSVP". Judges scan this live.
- Live feed: name, relative time, and a status chip (pending is pulsing grey, confirmed is green with a "Basescan ↗" link to `https://sepolia.basescan.org/tx/<payoutTx>`, failed is red with a Retry button that asks for the host PIN).
- Links: "Escrow contract ↗" (`https://sepolia.basescan.org/address/${process.env.NEXT_PUBLIC_ESCROW_ADDRESS}`), "Host wallet ↗", and "Created on-chain ↗" (createTx).
- Sponsor actions (collapsed panel, sponsor PIN input): **Fund with test USDC**, **Close & reclaim**. Disable both when status is closed, and show the close tx link (Basescan).
- If a new feed item arrives, flash the Verified tile green for 600ms. Small, but it sells the demo.
